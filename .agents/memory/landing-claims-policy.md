# Landing page claims policy

The public landing (`/`, `home.tsx`) must avoid invented/unverifiable numbers.

**Rule:** No fabricated social-proof figures ("milliers d'utilisateurs", "10× plus de contenu", fake ratings/logos). Use honest, factual phrasing instead.

**Why:** GrowIQ is under active Google Ads API + Meta platform compliance review where misleading claims create real risk; the product is new so headcount/result claims are unverifiable. The user explicitly chose "honest phrasing, no invented numbers."

**How to apply:** When editing landing copy or adding testimonials/stats, only state things that are true today (e.g. "gratuit pour commencer", "sans carte bancaire", "100% en français", "< 10 min"). Pricing plans (0€/29€/79€) ARE shown by user choice even though no billing system exists yet — Business CTA points to mailto:contact@growiq.tech, the others to /app.
